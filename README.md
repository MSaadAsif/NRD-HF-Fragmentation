# NRD heart failure readmission fragmentation study

Public report and disclosure-reviewed aggregate tables for the 2016–2022 Nationwide Readmissions Database analysis. The study estimates conditional observational associations; it does not estimate causal effects.

Open the [study report](https://msaadasif.github.io/NRD-HF-Fragmentation/) or download the [Word report](https://msaadasif.github.io/NRD-HF-Fragmentation/index.docx).
